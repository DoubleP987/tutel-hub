# Tutel promotional website

Static bilingual music/radio website at https://tutelbot.vercel.app. Light theme by default; saved dark/light and language choices. Thai follows a Thai browser locale; other locales use English.

Smooth transition is highlighted in the homepage, crossfade illustration and quick-start guide. Music settings are private and remembered per guild. Radio, random genres, queue and chat controls are documented. Source availability and preparation limits still apply.

The personal calendar is a separate product concern sharing the current repository/runtime. It is not advertised here and has no promotional command, link or feature card.

Deploy only `promo-site/`, with Framework Other and no build/install command. Public links live in `config.js`; never add credentials. Calendar deployment stays in the separate `vercel-public/` project.
