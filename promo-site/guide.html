TUTEL / GUIDE

A quick start with Tutel.

Everything you need for your first song and your server’s calendar.

MusicCalendarPermissionsPrivacy & data

Music & radio

Join a voice channel, then use /play query:song name or provide a supported track URL. Tutel joins and posts player controls with the latest music message.

Use /music settings source:youtube or soundcloud to choose a search source. Changing it requires Manage Server permission. Availability may vary by the host running the bot.

Use /randommusic for continuous single-song discovery. /stop stops playback and clears the queue; /leave disconnects.

Start radio with /radio list area:hatyai, then /radio play station:station name area:hatyai. An FM frequency is not an online stream; the station must provide an accessible live audio feed.

Calendar & daily summaries

A server manager uses /calendar setup channel:channel pin:PIN to choose a notification channel. This PIN only protects channel setup; it is not the web login password.

Use /calendar list for upcoming events or /calendar add for custom events. System holidays cannot be removed using the custom-event delete command.

The daily summary groups that day’s events into one message. The default is 07:00 in Asia/Bangkok time. Change it using /calendar config time:07:00 or the admin panel.

The private panel manages colours, categories, recurrence and all-day events. The public calendar is read-only and does not require a login.

Required permissions

Tutel needs View Channels, Send Messages, Embed Links, Attach Files, Read Message History, Connect and Speak. File attachments are used when a daily summary exceeds Discord’s message limit. This site’s invite does not request Administrator.

Channel overrides can change the bot role’s effective permissions. Check Connect and Speak in the actual voice room if playback is unavailable.

Privacy & data

Tutel stores information needed to work: events, server settings, reminder channels, notification message references, and admin accounts/sessions. Web passwords are stored as hashes.

Song files are not saved, and no member voice recording feature is added. The public calendar displays published events. Administrators should only enter details they intend to make public.

This promotional site has no analytics or submission form. It stores only your language preference in localStorage. Fonts load from Google Fonts. Discord, GitHub and calendar links open external services with their own policies.

For changes or removal of stored bot data, contact the administrator hosting the bot. This project is independent of Discord and music providers.
