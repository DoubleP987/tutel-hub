A quick start with Tutel.

Everything you need for your first song, live station and smooth transition.

Music & radio

Join a voice channel, then use /play query:song name or provide a supported track URL. Tutel joins and posts player controls with the latest music message.

Use /music settings source:youtube or soundcloud to choose a search source. Changing it requires Manage Server permission. Availability may vary by the host running the bot.

Use /randommusic for continuous single-song discovery. /stop stops playback and clears the queue; /leave disconnects.

Start radio with /radio list area:hatyai , then /radio play station:station name area:hatyai . An FM frequency is not an online stream; the station must provide an accessible live audio feed.

Smooth transitions

Open Settings on the music panel, then choose Enable smooth transition . Use Disable to return to ordinary playback. Manage Server permission is required; the setting is remembered separately for each server and is off by default.

When a song starts, Tutel prepares one successor in RAM. At the boundary, the old song fades down as the new song fades up over 350 ms . Skip uses the same short overlap through one continuous audio stream.

If you Skip before preparation finishes, the current song keeps playing while the next is prepared. Slow networks or unavailable sources may still cause waiting at a natural ending. Live radio uses its ordinary live stream.

Required permissions

Tutel uses View Channels, Send Messages, Embed Links, Read Message History, Connect and Speak. The invite does not request Administrator. Some deployments also allow Attach Files for bot responses.

Channel overrides can change the bot role’s effective permissions. Check Connect and Speak in the voice room if playback is unavailable.

Privacy & data

Tutel stores server preferences and references needed for its player controls. Music queues and temporary audio buffers live in memory. It does not save song files to disk or record member voices.

This promotional site has no analytics or submission form. It stores your language and theme choices in localStorage. Discord and GitHub links open services with their own policies.

For changes or removal of stored bot data, contact the administrator hosting the bot. Tutel is independent of Discord and music providers.
