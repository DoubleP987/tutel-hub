FAQ

A few things you might wonder.

Does Tutel save song files?

No. Audio is streamed through the server to Discord. Network traffic and temporary in-memory buffers are still needed.

Can I use YouTube links?

Yes, when YouTube is available from the host. YouTube and SoundCloud searches can be selected per server. Source availability and restrictions may vary.

Can every FM frequency be played?

Only stations with an accessible online audio stream can be played. Choose an area with the frequency, because different stations can share a frequency.

Who can change calendar settings?

Authorised server managers can configure Discord notifications. Channel setup requires the setup PIN. The web admin panel requires a separate login; the public calendar is read-only.

Why is a command or audio unavailable?

Check that Tutel is online, your channel permissions allow it to connect and speak, and the source is available. Registered slash commands may need a Discord refresh to appear.

Is Tutel affiliated with Discord?

No. Tutel is an independent project by Double_P. Discord, YouTube and SoundCloud names belong to their respective owners.
